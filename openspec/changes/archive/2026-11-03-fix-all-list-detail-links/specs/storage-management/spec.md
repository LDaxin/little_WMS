## ADDED Requirements

### Requirement: The all-storages list links to the detail page

The all-storages list SHALL link each row to the storage's detail page and SHALL
show the storage's type.

#### Scenario: Open a storage from the all list

- **WHEN** the user opens the all-storages list and follows a row's link
- **THEN** the storage's detail page is shown

#### Scenario: Type is shown

- **WHEN** the all-storages list is shown
- **THEN** each row shows the storage's type
